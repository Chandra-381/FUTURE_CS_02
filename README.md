# FUTURE_CS_02 - Phishing Detection & Awareness Report

## Objective
Analyze phishing email samples and produce user awareness guidelines.

## Methodology
- Manual email header inspection
- Sender domain verification
- Link inspection (hover preview)
- Content analysis (urgency, greetings, tone)
- Social engineering indicator identification

## Sample Classification

| Sample | Classification | Key Indicator |
|---|---|---|
| sample-1-phishing.eml | Phishing | Suspicious domain, urgency, threat |
| sample-2-safe.eml | Safe | Routine content, verified channel |
| sample-3-suspicious.eml | Suspicious | Unexpected invoice, attachment |

## Deliverables
- `phishing-detection-report.pdf` - Professional report
- Sample `.eml` files
- Evidence screenshots
